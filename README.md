# Ticket System

Spring Boot backend practice project.

## Project Goal

This project is created to learn backend development step by step using:

- Java
- Spring Boot
- REST API
- JSON Request/Response
- Validation
- Exception Handling

## Current Features

- Basic REST API
- DTO Request/Response handling
- JSON response
- Request validation
- Global exception handling

## Tech Stack

- Java
- Spring Boot
- Maven
- Postman
- Git & GitHub

## Learning Progress

This project is being developed step by step while learning backend concepts and Spring Boot fundamentals.
