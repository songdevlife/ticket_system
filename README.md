# Ticket System

Spring Boot backend practice project.

## Project Goal

This project is created to learn backend development step by step using:

- Java
- Spring Boot
- REST API
- Spring Data JPA
- MySQL
- JSON Request/Response
- Validation
- Exception Handling

## Current Features

- Basic REST API
- DTO Request/Response handling
- JSON response
- Request validation
- Global exception handling
- Ticket Entity
- Spring Data JPA Repository
- Create Ticket API (POST /tickets)
- MySQL database connection

## Tech Stack

- Java
- Spring Boot
- Spring Data JPA
- MySQL
- MySQL Workbench
- Maven
- Postman
- Git & GitHub
